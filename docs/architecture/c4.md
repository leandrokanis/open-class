# Arquitetura — Open Class (C4 Model)

> Documentação de arquitetura seguindo o [modelo C4](https://c4model.com/): Context → Container → Component.

## Nível 1 — Contexto do Sistema

Visão geral de quem usa o Open Class e com quais sistemas externos ele se integra.

```mermaid
C4Context
  title Sistema Open Class — Contexto

  Person(aluno, "Aluno", "Assiste aulas, acompanha progresso e gerencia sua matrícula.")
  Person(instrutor, "Instrutor", "Cria e organiza cursos, módulos e aulas.")

  System(openclass, "Open Class", "Plataforma de cursos online open source e self-hosted. Permite criar, organizar e consumir cursos gratuitos com vídeos do YouTube.")

  System_Ext(youtube, "YouTube", "Hospeda os vídeos das aulas. O conteúdo é incorporado via embed — nenhum vídeo é armazenado localmente.")

  System_Ext(smtp, "Servidor SMTP", "Envia e-mails transacionais: confirmação de conta e recuperação de senha.")

  Rel(aluno, openclass, "Navega por cursos, assiste aulas, acompanha progresso", "HTTPS")
  Rel(instrutor, openclass, "Cria e gerencia cursos e conteúdo", "HTTPS")
  Rel(admin, openclass, "Administra a instância", "HTTPS")

  Rel(openclass, youtube, "Incorpora vídeos das aulas", "iframe embed")
  Rel(openclass, youtube_api, "Valida vídeo e busca duração ao salvar aula", "HTTPS / REST")
  Rel(openclass, google_oauth, "Autentica usuários via OAuth 2.0", "HTTPS / OAuth2")
  Rel(openclass, smtp, "Envia e-mails transacionais", "SMTP / TLS")
```

## Nível 2 — Containers

Decomposição interna do Open Class em suas unidades de deploy e processos principais.

```mermaid
C4Container
  title Open Class — Containers

  Person(usuario, "Usuário", "Aluno, Instrutor ou Admin")

  System_Boundary(openclass, "Open Class") {
    Container(ui, "UI", "TypeScript · React (futuro)", "Interface web responsiva. Consome a API via REST. Ainda não implementada — planejada para Fase 3.")
    Container(api, "API", "TypeScript · NestJS", "Núcleo da plataforma. Expõe endpoints REST para autenticação, gestão de usuários, cursos, matrículas e progresso.")
    Container(migrator, "Migrator", "TypeScript · Drizzle Kit", "Container de execução única que aplica as migrations do schema ao banco antes do API subir.")
    ContainerDb(db, "Banco de Dados", "PostgreSQL 16", "Armazena usuários, cursos, módulos, aulas, matrículas e tokens de reset de senha.")
  }

  System_Ext(youtube, "YouTube", "Hospedagem de vídeos")
  System_Ext(youtube_api, "YouTube Data API v3", "Validação de vídeo e busca de duração")
  System_Ext(google_oauth, "Google OAuth 2.0", "Login social")
  System_Ext(smtp, "Servidor SMTP", "E-mails transacionais")

  Rel(usuario, ui, "Acessa via browser", "HTTPS")
  Rel(ui, api, "Consome endpoints REST", "HTTPS / JSON")
  Rel(usuario, api, "Acesso direto à API (CLI / mobile / testes)", "HTTPS / JSON")

  Rel(api, db, "Lê e grava dados", "TCP · Drizzle ORM")
  Rel(migrator, db, "Aplica migrations do schema", "TCP · Drizzle Kit")

  Rel(api, google_oauth, "Redireciona e valida tokens OAuth2", "HTTPS")
  Rel(api, smtp, "Envia e-mails", "SMTP")
  Rel(api, youtube_api, "Valida vídeo e busca duração ao salvar aula", "HTTPS / REST")
  Rel(ui, youtube, "Incorpora vídeos das aulas", "iframe embed")
```

## Nível 3 — Componentes da API

Decomposição interna do container **API** (NestJS) em seus módulos e responsabilidades.

```mermaid
C4Component
  title API (NestJS) — Componentes

  Container_Ext(db, "PostgreSQL", "Banco de dados relacional")
  Container_Ext(smtp, "SMTP", "Servidor de e-mail")
  Container_Ext(google_oauth, "Google OAuth 2.0", "Provedor de identidade")
  Container_Ext(youtube_api, "YouTube Data API v3", "Validação de vídeo e metadados")

  Container_Boundary(api, "API — NestJS") {

    Component(auth_module, "AuthModule", "NestJS Module", "Orquestra autenticação: registro, login e/por senha, recuperação de senha e login social Google.")
    Component(users_module, "UsersModule", "NestJS Module", "CRUD de usuários e perfis. Expõe dados de usuário para outros módulos.")
    Component(database_module, "DatabaseModule", "NestJS Module", "Fornece a conexão com o banco (pool pg + Drizzle) como provider global 'DATABASE'.")

    Component(courses_module, "CoursesModule", "NestJS Module", "CRUD de cursos: criação, edição, publicação e controle de visibilidade. Restrito a instrutores e admins.")
    Component(modules_module, "ModulesModule", "NestJS Module", "CRUD de módulos dentro de um curso. Inclui endpoint de reordenação atômica de módulos.")
    Component(lessons_module, "LessonsModule", "NestJS Module", "CRUD de aulas dentro de um módulo. Valida URL do YouTube, busca duração automaticamente e gerencia recursos (links externos). Inclui endpoint de reordenação atômica de aulas.")
    Component(youtube_service, "YouTubeService", "NestJS Service", "Encapsula chamadas à YouTube Data API v3: valida se o vídeo existe/é embeddável e retorna a duração em segundos.")

    Component(local_strategy, "LocalStrategy", "Passport Strategy", "Valida e-mail e senha no login. Usa bcrypt para comparar o hash armazenado.")
    Component(jwt_strategy, "JwtStrategy", "Passport Strategy", "Valida o JWT extraído do cookie httpOnly em cada requisição protegida.")
    Component(google_strategy, "GoogleStrategy", "Passport Strategy (condicional)", "Processa o callback OAuth2 do Google. Ativada apenas se as credenciais Google estiverem configuradas.")

    Component(throttler, "ThrottlerGuard", "NestJS Guard (global)", "Rate limiting global: 60 requisições por minuto por IP.")
    Component(users_repo, "UsersRepository", "Repository", "Queries SQL de usuários via Drizzle ORM. Abstrai o acesso direto ao banco no domínio de usuários.")
    Component(mail_service, "MailService", "Service", "Envia e-mails de recuperação de senha via Nodemailer.")
  }

  Rel(auth_module, local_strategy, "Usa para login e/senha")
  Rel(auth_module, jwt_strategy, "Usa para autenticação por cookie")
  Rel(auth_module, google_strategy, "Usa para login Google (opcional)")
  Rel(auth_module, users_module, "Delega queries de usuário")
  Rel(auth_module, mail_service, "Solicita envio de e-mail de reset")

  Rel(users_module, users_repo, "Executa queries")
  Rel(users_repo, database_module, "Recebe conexão 'DATABASE'")
  Rel(database_module, db, "Abre pool de conexões")

  Rel(courses_module, database_module, "Recebe conexão 'DATABASE'")
  Rel(modules_module, database_module, "Recebe conexão 'DATABASE'")
  Rel(lessons_module, database_module, "Recebe conexão 'DATABASE'")
  Rel(lessons_module, youtube_service, "Solicita validação e duração do vídeo")

  Rel(mail_service, smtp, "Envia e-mails via SMTP")
  Rel(google_strategy, google_oauth, "Valida token de acesso")
  Rel(youtube_service, youtube_api, "Consulta metadados do vídeo", "HTTPS / REST")
```

## Decisões de Arquitetura

| Decisão | Escolha | Justificativa |
|---------|---------|---------------|
| Autenticação | JWT stateless em cookie httpOnly | Sem estado no servidor; compatível com deploy single-instance sem Redis |
| ORM | Drizzle ORM | Type-safe, zero overhead, migrations explícitas em SQL |
| Vídeos | YouTube embed | Elimina custo e complexidade de storage de mídia |
| Deploy | Docker Compose | Self-hosted simples; target homelab < 256 MB RAM idle |
| Monorepo | pnpm workspaces + Turborepo | Compartilhamento de `packages/db` entre apps sem publicação no npm |
| Rate limiting | ThrottlerModule (in-memory) | Suficiente para < 1000 usuários; sem Redis na Fase 1 |
| Validação YouTube | YouTube Data API v3 (server-side) | Garante que apenas vídeos acessíveis e embeddáveis sejam salvos; duração obtida da fonte oficial |
| Duração da aula | Buscada no save, armazenada como integer (segundos) | Evita chamada à API a cada leitura; formato simples de exibir e somar no currículo |
| Reordenação | Endpoint recebe array completo de IDs na nova ordem | Operação atômica e sem ambiguidade; evita lógica de troca par-a-par no cliente |
